# Fridge Roast — One Line, Biggest Laugh

A one-line roast of a smart fridge, built for the make.fun bounty
[Fridge Roast: One Line, Biggest Laugh](https://make.fun/bounty/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb).

## What it does

`main.ts` writes a single UTF-8 line (1–200 characters, no trailing newline) to
`/output/entry.txt`. The line roasts the smart fridge itself — its firmware-gated
ice maker, its subscription-to-stay-cold app, and its expiry beeps — and lands on
the turn that the fridge is snitching on cheese that expired on its own watch.

## Run

```sh
node main.ts
cat /output/entry.txt
```
